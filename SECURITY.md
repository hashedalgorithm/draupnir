# Security Policy

## Supported Versions

Draupnir is currently pre-1.0 and released as a single rolling `0.x` line.
Only the latest published version on npm receives security fixes.

| Version        | Supported          |
| -------------- | ------------------- |
| Latest (`0.4.x`) | :white_check_mark: |
| < 0.4            | :x:                 |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public
GitHub issue. Instead, report it privately:

- Email: sanjaykumarcena@gmail.com
- Or use [GitHub's private vulnerability reporting](https://github.com/hashedalgorithm/draupnir/security/advisories/new)

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a minimal proof-of-concept
- Any suggested remediation, if you have one

You should receive an acknowledgment within a few days. Once the issue is
confirmed, a fix will be prepared and a new version published to npm; the
reporter will be credited unless anonymity is requested.
